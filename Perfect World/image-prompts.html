使い方 / How to Use

  1. 各カードのプロンプトを「コピー」ボタンでコピー
  2. Nano Banana2 にペーストして生成
  3. 生成した画像を images/ フォルダに保存（例：hero-bg.jpg）
  4. HTML の background-color: #ccc を background-image: url(images/hero-bg.jpg) に差し替え
  5. ネガティブプロンプトも必ず入力してテイストを守る
