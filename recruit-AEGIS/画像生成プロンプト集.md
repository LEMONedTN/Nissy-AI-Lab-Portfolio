# AEGIS CYBER 採用サイト｜画像生成プロンプト集

サイト内の `.ph`（PLACEHOLDER）**全31箇所**に当てはめる画像を生成するためのプロンプト集です。
すべて日本語プロンプトで、そのままChatGPT・Gemini等の画像生成にコピペして使えます。

---

## 使い方（3つのお約束）

1. **サイズ厳守** … 各プロンプトに「生成サイズ」を明記しています。プレースホルダーと同じ縦横比で作ってください。多少大きく作って後でトリミングしてもOK（比率さえ合っていれば崩れません）。
2. **人物は日本人** … 社員写真はすべて日本人。しかも同じ人物が複数ページに登場するので、後述の「登場人物カタログ」の設定を毎回コピペして使うと顔がブレません。
3. **サイトのテイストに合わせる** … このサイトは「サイバーセキュリティ企業のダーク×シアン」トーン。各プロンプト末尾の【共通スタイル】を必ず付けることで、写真同士が浮きません。

> 💡 **コツ**：「登場人物カタログ」の人物文＋各プロンプトの状況文＋【共通スタイル】、この3つを繋げて1つのプロンプトにするのが基本形です。

## ✅ 実際に用意する画像の枚数まとめ

プレースホルダーは全31箇所だけど、同じ人物・使い回しを考えると、実際に生成が必要なのはこれだけ。

| 種類 | 作る枚数 | 内訳 |
|---|---|---|
| 空間・風景 | 11枚 | index 7＋about 1＋workstyle 3 |
| 社員バストアップ（4:3・カード用） | 6枚 | 6名分 |
| 社員ポートレート（1:1・モーダル/座談会用） | 6枚 | カードと同一人物の正方形 |
| チャットアイコン | 0枚 | 座談会の4枚を流用 |
| **合計** | **約23枚** | 31箇所を23枚でカバー |

> 人物は6名。ページをまたいで同じ人物が出るので、**同じ服装・同じ顔**で作るのが崩さないコツ。「登場人物カタログ」の設定文をコピペするのが一番早いです。
