## 2. デザインテイスト（最重要）

**コンセプト：ダークネイビー × ゴールドの、静かな高級感。**
煽らず、数字と事実で信頼を積み上げるトーン。若い世代向けだが、ポップにはせず「先を行く大人の落ち着き」を出す。

### カラーパレット（CSS変数で定義すること）

```css
:root {
  --color-base-dark:   #0F1B2D; /* ダークネイビー：FV・区切り・CTA帯・フッター */
  --color-base-light:  #F5F6F8; /* オフホワイト：本文セクション */
  --color-white:       #FFFFFF; /* カード背景 */
  --color-accent:      #C9A96A; /* ゴールド：英字ラベル・数字・罫線・主CTA */
  --color-accent-deep: #A88748; /* ゴールド濃：ホバー */
  --color-line:        #06C755; /* LINEグリーン：サブCTAのみ */
  --color-highlight:   #2E6BE6; /* ブルー：比較表の自社列のみ */
  --color-text:        #1A1A1A; /* 本文 */
  --color-text-sub:    #6B7280; /* 補足・注釈 */
  --color-text-invert: #FFFFFF; /* 暗背景上の文字 */
  --color-border:      #D8DCE3; /* 罫線 */
}
```

### タイポグラフィ

```css
--font-jp: 'Noto Sans JP', sans-serif;   /* 和文（明朝は使わない） */
--font-en: 'Montserrat', sans-serif;      /* 英字ラベル・数字 */
```

- 見出し：太めのボールド（700〜900）、字間 `letter-spacing: 0.04em`、1行を短く折り返して「塊」で見せる
- **各セクションの頭に、小さいゴールドの英字ラベルを必ず配置**（例：`Problem` `Why COMPASS` `Performance`）。font-size 12〜13px / letter-spacing 0.2em / 大文字始まり。**これが高級感の要**
- 数字は極端に大きく（48〜72px）＋ゴールド。単位は小さく添える
- 注釈はグレー極小（11px）で丁寧に入れる。これが誠実さを演出する

### 質感ルール

- **box-shadow はほぼ使わない。** 境界は「背景色の差」と「1pxのゴールド罫線」で作る
- 角丸は中〜大（8〜16px）で柔らかさを担保
- 余白はたっぷり（セクション上下 padding: 100px / SP時 64px）
- 写真枠は `background-color: #ccc` のプレースホルダー。人物写真枠には暗いオーバーレイ（`rgba(15,27,45,0.55)`）を重ねて文字を載せる想定のスタイルを用意する
- イラスト・絵文字は使わない。アイコンはチェック・矢印など最小限

### セクション背景の交互ルール

**暗 → 明 → 暗 → 明 のサンドイッチ構造**でスクロールのリズムを作ること。濃紺ブロックが「章の区切り」として機能する。

## 3. ページ構成（PASBECONAの法則）

上から順に以下11ブロックを縦1カラムで配置。**グローバルナビは設置せず**、ページ内アンカーのみの追従ヘッダー（スクロールで出現、右端にCTAボタン）とする。CTAは**計5回**反復。

---

### ■ Block 01 ─ ファーストビュー（P：Problem／問題提起）
背景：ダークネイビー。左に人物写真プレースホルダー、右にコピー。

- 上部に小バッジ3つ：`宅建資格 不要` `初期費用 0円` `完全オンライン`
- 英字ラベル：`For the next generation`
- **メインコピー：「給料は増えないのに、物価だけ上がっていく。」**
- サブコピー：「20代の平均昇給額は年間およそ1万円。このまま5年働いても、手取りはほとんど変わりません。COMPASSは、その現実を一番早く変えるための選択肢です。」
- 主CTA：`今すぐ面談を申し込む` / サブCTA：`資料をLINEで受け取る`
- CTA下注釈：「※無理な勧誘は一切ありません／10:00〜22:00 対応」
- 右下に実績数値3つ横並び：`1,480名` 登録パートナー数 ／ `85%` 報酬還元率 ／ `72%` 未経験スタート比率

---

### ■ Block 02 ─ 共感（A：Affinity／親近感）
背景：オフホワイト。中央寄せ。

- 英字ラベル：`We know how you feel`
- 見出し：「そのモヤモヤ、あなただけじゃありません。」
- 悩みカード4枚（2×2グリッド、白背景＋ゴールド細罫）
  1. 「副業を調べても、情報商材ばかりで何が本物か分からない」
  2. 「初期費用が数十万円と聞いた瞬間、手が止まった」
  3. 「本業が忙しくて、まとまった時間なんて取れない」
  4. 「頑張りたいのに、何から始めればいいのか分からない」
- 締め文：「COMPASSに登録した方の72%が、まったくの未経験からのスタートでした。」

---

### ■ Block 03 ─ 解決策（S：Solution／解決）
背景：ダークネイビー。

- 英字ラベル：`Solution`
- 見出し：「あなたは、"紹介する"だけでいい。」
- 3ステップを横並びカードで（番号はゴールドの大きな数字）
  - `01` **つなぐ** ─ 引っ越しや住み替えを考えている知人を、COMPASSに紹介する
  - `02` **任せる** ─ 物件の提案・内見・契約手続きは、COMPASSの宅建士がすべて対応
  - `03` **受け取る** ─ 成約時、紹介手数料の85%があなたの報酬になる
- 締め文：「あなたの作業は、ほぼ"つなぐ"だけ。1件あたりの実働は平均1.5時間です。」

### ■ Block 04 ─ 収入シミュレーション（B：Benefit／利益）
背景：オフホワイト。

- 英字ラベル：`Your Benefit`
- 見出し：「月に2件つなぐだけで、手取りがもう一段上がる。」
- **2列比較テーブル**（左：本業のみ／右：本業＋COMPASS。右列だけ `--color-highlight` の淡い背景＋ヘッダーをブルーで塗る）

| | 本業のみ | 本業＋COMPASS |
|---|---|---|
| 月の副収入 | 0円 | 約18.6万円 |
| 年間の副収入 | 0円 | 約223万円 |
| 月の稼働時間 | ─ | 約3時間 |
| 必要な資格 | ─ | なし |

- 下に注釈：「※賃貸1件あたりの平均報酬9.3万円（2025年実績・当社調べ）を月2件成約した場合の試算です。成果を保証するものではありません。」
- **稼働イメージのカレンダー風マトリクス表**（月〜日 × 4週）を配置し、活動する日にだけゴールドのドットを置く。キャプション「平日夜と土日の"すきま"だけで完結します。」
- CTA①：`今すぐ面談を申し込む`

### ■ Block 05 ─ 実績データ（E：Evidence／証拠）

## 4. 技術仕様

- `<meta charset="UTF-8">` を必ず含める
- Google Fonts を読み込む（Noto Sans JP / Montserrat）
- `<title>`：`COMPASS｜資格ゼロ・初期費用ゼロではじめる、紹介型の副業`
- `<meta name="description">`：`宅建資格不要・初期費用0円。知人を紹介するだけで報酬率85%。20代・30代の会社員が本業と両立しながら始められる、紹介型の副業「COMPASS」。`
- OGPタグ、favicon の記述も入れる（画像パスはダミーで可）
- **レスポンシブ必須**（ブレイクポイント 768px以下）。SPでは比較表を横スクロール、体験談カードを横スワイプに
- 画像が入る箇所はすべて `background-color: #ccc` のプレースホルダー（`aspect-ratio` で高さを確保）
- JavaScript は最小限（追従ヘッダーの表示切替とスムーススクロールのみ）。FAQは `<details>` でJSなし
- CTAボタンはすべて `#contact` へのアンカー（またはダミーの `#`）
- セマンティックHTML（`<header>` `<section>` `<footer>`）とアクセシビリティ（alt属性・aria-label）に配慮

## 6. 制作時の注意

- 参考サイトのHTML・文言をコピーしない。**構造と配色の考え方のみ**を踏襲する
- ダミーテキストに「テキストが入ります」は絶対に使わない。すべて業種・ターゲットに合った自然な日本語にする
- ターゲットが20代後半〜30代前半のため、体験談の人物は20代後半〜30代前半・男女バランスよく設定する
- 煽り表現・断定的な収益保証表現は避け、必ず注釈で個人差を明記する
