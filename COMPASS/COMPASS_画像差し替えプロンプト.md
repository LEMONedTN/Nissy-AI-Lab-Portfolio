# COMPASS LP 画像差し替えプロンプト

`index.html` / `style/style.css` で作成済みのLPには、画像の入る箇所が **6ヶ所** あります。
現在はすべて `background-color: #ccc` のグレーのプレースホルダーです。
以下の指示に従って、6ヶ所すべてに画像を当ててください。

---

## 0. 前提：このLPのテイスト

| 項目 | 内容 |
|---|---|
| サービス | 不動産紹介パートナー「COMPASS」（副業マッチング） |
| ターゲット | 20代後半〜30代前半の日本人会社員（男女） |
| デザインコンセプト | **ダークネイビー × ゴールドの、静かな高級感** |
| トーン | 煽らない。数字と事実で信頼を積み上げる。落ち着いた大人の空気 |

**この空気を壊す画像は、1枚でも入れたらLP全体が破綻します。** 迷ったら「静かで、上品で、リアルか」で判断してください。

## 1. 全画像に共通する絶対ルール

### 必須条件

1. **被写体は必ず日本人**（アジア系全般ではなく、日本人と自然に認識できる人物）
2. **年齢は20代後半〜30代前半**。40代以上・学生風は不可
3. **服装はビジネスカジュアル〜オフィスカジュアル**（ネイビー・グレー・白・黒・ベージュ）
4. **彩度は低め、色温度はやや寒色〜ニュートラルで6枚すべて統一**
5. **自然光ベース**。人工的なライティングは避ける
6. **表情は自然体**。作り笑い・キメ顔ではなく、穏やかな表情か自然な仕事中の表情

### 禁止事項（1つでも当てはまったら不採用）

- 外国人モデル、明らかに海外のオフィス・街並み
- 原色・蛍光色・極彩色（赤いスーツ、黄色い壁、カラフルな背景など）
- 白背景の切り抜き素材、いわゆる「素材集っぽい」写真
- ガッツポーズ、両手を上げる、ハイタッチ、指差し、OKサイン、腕組みドヤ顔
- 札束、コイン、電卓アップ、右肩上がりのグラフ、家の模型、鍵の受け渡し
- ヘッドセットを付けたコールセンター風
- 過度なレタッチ、HDR、強いビネット、フィルム風の色被り
- イラスト・3DCG・アイコン素材（**このLPは写真のみ**）

### 統一チェック

6枚を横に並べたとき、**同じフォトグラファーが同じ日に撮ったように見えること**。
色温度・粒状感・彩度がバラバラなら、Lightroom等で揃えてから使ってください。

### ① ファーストビュー背景（最重要）

| 推奨サイズ | 2400 × 1600px 以上（横長） |
| ファイル名 | `hero.webp` |

**内容**：20代後半〜30代前半の日本人男性または女性が、**オフィス街または駅・ビル前を歩いている／立ち止まっている**シーン。スーツまたはジャケット。朝〜昼の自然光。

**構図の指定（重要）**：
このFVは、**画面左側に濃紺のグラデーションがかかり、その上にキャッチコピーとボタンが乗ります。**

- 人物の顔が画面の上下中央付近に来る構図が理想
- 背景がゴチャついた写真（看板・人混み・派手な色）は不可

**避けるもの**：満面の笑みでカメラ目線、スーツで両手を広げる、朝日をバックにシルエット

## 3. ファイルの配置とファイル形式

```
index.html
style/
├── reset.css
└── style.css
assets/
└── images/
    ├── hero.webp
    ├── voice-1.webp
    ├── voice-2.webp
    ├── voice-3.webp
    ├── support.webp
    └── cta.webp
```

- 形式は **WebP**（品質80〜85）。フォールバックが必要なら同名の `.jpg` も併置
- 1枚あたり **300KB以内**を目安に圧縮（hero と cta は 500KB以内でも可）
- 画像は**必ず既存のアスペクト比に合わせてトリミング**してから書き出すこと

## 4. 実装方法（style.css の書き換え）

`style/style.css` の該当箇所を、以下の通り書き換えてください。
**HTMLは触らずCSSだけで完結します。**

### ① ファーストビュー

```css
/* 変更前 */
.hero__media {
  position: absolute;
  inset: 0;
  background-color: var(--ph);
}

/* 変更後 */
.hero__media {
  position: absolute;
  inset: 0;
  background-color: var(--navy);
  background-image: url("../assets/images/hero.webp");
  background-size: cover;
  background-position: 72% center; /* 人物が右寄りなので右側を見せる */
  background-repeat: no-repeat;
}
```

### ⑤ サポート写真

```css
.ph--support {
  aspect-ratio: 4 / 3;
  background-image: url("../assets/images/support.webp");
  background-size: cover;
  background-position: center;
}
```

### ⑥ 最終CTA背景

```css
.final__bg {
  position: absolute;
  inset: 0;
  background-color: var(--navy);
  background-image: url("../assets/images/cta.webp");
  background-size: cover;
  background-position: center 40%;
}
```

### ② ③ ④ 利用者の声

`.ph--face` は3枚とも別画像なので、個別指定を追加してください。

```css
.ph--face {
  aspect-ratio: 3 / 4;
  background-size: cover;
  background-position: center 30%; /* 顔が上寄りなので上側を見せる */
}

.voice:nth-child(1) .ph--face { background-image: url("../assets/images/voice-1.webp"); }
.voice:nth-child(2) .ph--face { background-image: url("../assets/images/voice-2.webp"); }
.voice:nth-child(3) .ph--face { background-image: url("../assets/images/voice-3.webp"); }
```

### 共通の注意

- `background-color: var(--ph);` の記述は、画像を入れたスロットからは**すべて削除**すること（グレーが透けるのを防ぐため）
- `--ph` 変数自体は他で使っていなければ削除して構いません
- `background-position` は、実際の写真に合わせて微調整すること（人物が切れていないか必ず目視確認）

## 5. パフォーマンス対応（任意だが推奨）

FVの画像はLCP（表示速度スコア）に直結するため、`index.html` の `<head>` 内、CSS読み込みの直前に以下を追加してください。

```html
<link rel="preload" as="image" href="assets/images/hero.webp" fetchpriority="high">
```

また、OGP画像も差し替えておくこと。

```html
<meta property="og:image" content="https://example.com/assets/images/ogp.jpg">
```

OGP用は **1200 × 630px**。FVの写真をトリミングし、上に白文字で「COMPASS」とキャッチコピーを載せたものを別途用意してください。

## 6. alt / aria-label の更新

各スロットには既に `role="img"` と `aria-label` が入っています。
**実際に採用した写真の内容と食い違う場合は、`aria-label` の文言も合わせて修正**してください。

| 箇所 | 現在の aria-label |
|---|---|
| `.hero__media` | 通勤する20代後半の会社員のイメージ写真 |
| `.ph--face` ×3 | 佐藤 遥さんの写真 ／ 中村 拓海さんの写真 ／ 林 美咲さんの写真 |
| `.ph--support` | サポーターがオンラインで相談に応じている様子 |
| `.final__bg` | 街を歩く若い会社員のイメージ写真 |

※ `.final__bg` は装飾目的の背景なので、`role="img"` と `aria-label` を削除して `aria-hidden="true"` に変更しても構いません。

## 8. 最終チェックリスト

差し替え後、以下をすべて確認してください。

- [ ] グレー（#ccc）が1ヶ所も残っていない
- [ ] 6枚すべて日本人・20代後半〜30代前半
- [ ] 6枚を並べて色温度・彩度が揃っている
- [ ] FVの人物が画面右寄りにあり、左側のコピーと重なっていない
- [ ] FVの画像の上でキャッチコピーとボタンが問題なく読める
- [ ] 利用者の声3枚とも、顔が上半分にあり、下部の氏名テキストと重なっていない
- [ ] サポート写真がダークネイビー背景から浮いていない
- [ ] 最終CTAの見出しが、濃いオーバーレイ越しでもはっきり読める
- [ ] スマホ幅（390px）でも人物の顔が切れていない
- [ ] 各画像が推奨容量以内に圧縮されている
- [ ] `aria-label` の内容が実際の写真と一致している
- [ ] ブラウザのコンソールに404（画像パス誤り）が出ていない
