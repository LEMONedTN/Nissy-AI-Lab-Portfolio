## 2. 【最重要】サイズ規定 — 比率は絶対厳守

**指定された比率と完全に一致する画像を作成してください。**

CSSは `object-fit: cover` で表示するため、**比率がずれた画像は自動的に上下または左右が切り落とされます。** 正方形の枠に長方形の画像を入れると、見せたい顔や動きが画面外に切れてしまいます。これは絶対に避けてください。

### 書き出し仕様

- **形式**：`.webp`（品質80前後）／WebPが難しい場合は `.jpg`（品質85前後）
- **1枚あたり**：200KB以下を目安（スマホ表示のため軽量化を優先）
- **保存先**：`images/` フォルダを新規作成し、その中に格納

### 構図上の注意（切れ防止）

生成AIは指定比率どおりに出ないことがあります。**必ず書き出し前に比率を確認**し、ずれていたら以下のいずれかで対処してください。

1. 生成時のアスペクト比パラメータを指定し直して**作り直す**
2. 指定比率でトリミングする（このとき**主要被写体が中央寄りに収まる**ように）

また、被写体の**顔・手・足先が画像の端ギリギリに来ないよう**、上下左右に余白を持たせて構図を組んでください。多少トリミングされても破綻しない保険になります。

## 4. 全画像に共通する必須ルール

### ✅ 必ず守ること

1. **登場人物は全員 日本人**（アジア系ではなく、日本人として自然な顔立ち・髪色・髪質）
2. **子どもは小学生（6〜12歳）の範囲**。中高生に見える体格・顔立ちにしない
3. **明るく、やわらかく、彩度は高めだが目に痛くない**トーンで統一
4. **9枚すべてで色温度・明るさ・彩度を揃える**（1枚だけ暗い／青白いといったバラつきを出さない）
5. サイト配色（`#FF7EB3` / `#6FD8CB` / `#B79BEB` / `#FFD44D`）のいずれかが各画像に含まれること
6. 背景はシンプルに。**情報量が多い背景は、スマホの小さい画面で潰れる**
7. 顔がはっきり判別できる解像度・ピント

### 🚫 絶対にやってはいけないこと

1. **指定比率と異なるサイズで作成すること**
   　→ 正方形の枠に長方形を入れると、見せたい部分が切れます
2. **日本人以外の人物を使うこと**
3. **サイトのテイストから大きく外れる画像**
   　→ 具体的には：暗い／モノトーン／シック／高級感／リアルすぎる報道写真風／ホラー調／ヴィンテージ加工
4. **子どもの服装・ポーズが年齢に不相応なもの**
   　→ 露出の多い服、濃いメイク、大人びた色気のある表情やポーズ、体のラインを強調する構図は一切不可。すべて**健全で年齢相応**、活動している姿を中心に
5. **実在の子役・タレント・キャラクターに似せること**（肖像権・著作権侵害のため）
6. 画像内に**文字・ロゴ・透かしを入れること**（文字はすべてHTML側で表示します）
7. 極端な広角レンズによる顔の歪み、指の本数の破綻（**生成後に必ず手指をチェック**）

## 5. 完成後の差し替え手順

画像が9枚そろったら、以下の手順でLPに反映します。

### STEP 1：フォルダを作る

`index.html` と同じ階層に `images/` フォルダを作成し、9枚を格納します。

```
kidz/
├── index.html
├── images/          ← 新規作成
│   ├── img-hero.webp
│   ├── img-about.webp
│   ├── img-course01.webp
│   ├── img-course02.webp
│   ├── img-course03.webp
│   ├── img-chance01.webp
│   ├── img-chance02.webp
│   ├── img-chance03.webp
│   └── img-welcome.webp
└── style/
    ├── reset.css
    └── style.css
```

### STEP 2：`style.css` の末尾に追記

```css
/* ============================================
   画像差し替え後の表示調整
   ============================================ */
.ph img {
  width: 100%;
  height: 100%;
  object-fit: cover;   /* 枠いっぱいに、比率を保って表示 */
  object-position: center;
  border-radius: inherit;
}
.ph:has(img) {
  background: none;    /* 画像が入ったらグレー背景を消す */
}
```

### STEP 3：`index.html` のプレースホルダーを置き換える

現在のプレースホルダーは、すべて次の形をしています。

```html
<figure class="ph ph--hero" role="img" aria-label="メインビジュアル">
  <figcaption class="ph__label">MAIN VISUAL<br><small>1200 × 1400px 目安</small></figcaption>
</figure>
```

これを、次のように書き換えます。**`figure` タグと `class` はそのまま残し、中身の `figcaption` を `img` に差し替える**のがポイントです（比率の指定が `figure` 側にあるため）。

```html
<figure class="ph ph--hero">
  <img src="images/img-hero.webp" alt="キラリ☆キッズスクールのレッスンを楽しむ女の子たち" width="1200" height="1400">
</figure>
```
