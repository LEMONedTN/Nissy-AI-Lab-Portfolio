Our Program

あなたの目標に合わせたプログラム

Program 01

ダイエット・減量

代謝を上げながら脂肪を効率よく燃やす最適なアプローチで、リバウンドしない身体づくりを実現します。有酸素運動と筋力トレーニングを組み合わせ、食事指導も含めた総合的なサポートで理想の体重・体型へ。

#体重管理 #体脂肪減少 #食事管理 #代謝アップ

Program 02

ボディメイク

単なる体重変化ではなく、プロポーションや筋肉のバランスにこだわった美しい身体へ。ヒップアップ・バストアップ・逆三角形ラインなど、目標に応じた部位別アプローチで理想のシルエットを実現します。

#筋力アップ #ヒップアップ #美ボディ #バルクアップ

Program 03

健康維持・機能改善

慢性的な腰痛・肩こりの軽減、姿勢の改善、機能的な動きの獲得を目指します。スポーツ科学と機能解剖学に基づいたアプローチで、年齢を重ねても活動的に過ごせる身体をつくります。

#姿勢改善 #腰痛改善 #健康寿命 #機能改善
