# 土井クリニックLP 画像生成プロンプト集

このLP内の「#ccc（グレー）」プレースホルダー全9箇所に入れる画像を生成するためのプロンプトです。
**画像生成AI（Midjourney / DALL·E / Stable Diffusion / Adobe Firefly など）** にそのまま貼り付けて使えます。

---

## 使い方・共通ルール（すべての画像に適用）

各プロンプトの前に、必ず下記の【共通スタイル】を付けてください。
これで「日本人」「テイスト維持」「サイズ・比率一致」の3条件を満たします。

### 【共通スタイル】（全画像共通・コピペ用）
```
実写風・フォトリアルの高品質写真。被写体は必ず日本人（アジア系日本人、50〜60代を中心に）。
清潔感のある明るいモダンな歯科クリニックが舞台。自然光でやわらかく、温かみと高級感のある雰囲気。
配色はネイビー・ホワイト・ゴールドを基調にしたトーンに馴染むこと。信頼感・安心感を最優先。
高解像度、リアルな肌・自然な表情。文字・ロゴ・透かし・イラストは一切入れない。
```

### 【共通ネガティブ（除外条件）】
```
西洋人・白人・黒人などの非日本人、外国人、子ども、過度なCG感、
文字/ロゴ/ウォーターマーク、歯や指の破綻、不自然な笑顔、暗い雰囲気、医療器具の生々しさ
```

### サイズ・比率の合わせ方（重要）
- 各画像は **指定のアスペクト比ちょうど** で生成してください（顔がはみ出す・見切れるのを防ぐため）。
- 画像を差し込む際は CSSで `object-fit: cover;` を使うと、多少ズレても中央基準で自然に収まります。
- Midjourneyなら `--ar 比率`、DALL·E/Fireflyなら生成サイズを下記pxに設定してください。

## ① ファーストビュー（メインビジュアル）
- **場所**：最上部ヒーロー / 「院長・施術シーン写真」

胸から上のミディアムショット。--ar 5:4
```

```

## 補足
- **英語ベースのツール（Midjourney等）を使う場合**：各プロンプト冒頭に `Japanese people, photorealistic,` を付けると「日本人」がより確実に反映されます。
- **地図**はGoogleマップ埋め込み済みのため、画像生成は不要です。
- 生成後、画像を差し込む際は各プレースホルダーの `<div class="...ph">` を `<img>` に置き換えるか、CSSで `background-image` を指定してください（希望あれば差し込み作業も対応します）。
