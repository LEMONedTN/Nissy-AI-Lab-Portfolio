# デバン（DEBAN）会員登録LP - 納品データ

キッチンカー・テント催事・物産催事 事業者向け／ダイレクトマッチングプラットフォームの
無料会員登録LPです。**サーバーにアップロードすればそのまま公開できる状態**でお渡ししています。

---

## 1. ファイル構成

```
deban-lp/
├── index.html          … LP本体（1ページ完結）
├── style/
│   ├── reset.css       … ブラウザ標準スタイルのリセット
│   └── style.css       … LPのスタイル一式（レスポンシブ含む）
├── js/
│   └── main.js         … 開閉・スクロール演出・フォーム制御
├── images/             … 画像一式（現在はプレースホルダー）
└── README.md           … 本ファイル
```

## 2. 公開手順

`deban-lp` フォルダの中身を、サーバーの公開ディレクトリにそのままアップロードしてください。
相対パスのみで構成しているため、サブディレクトリ配置でも動作します。

外部読み込みはGoogle Fonts（Noto Sans JP / Montserrat）のみです。
社内サーバー等で外部通信が制限される場合は、フォントファイルをローカルに同梱する形へ変更可能です。

## 5. テキスト・数値の差し替え

デザイン確認用のサンプル値が入っている箇所です。実データへの差し替えをお願いします。

| 箇所 | 内容 |
| --- | --- |
| 実績バー（`.stats`） | 登録事業者数／掲載催事数／成立マッチング数。`data-count` の数値を変更するとカウントアップも追従します |
| 利用者の声（`.voice`） | コメント・肩書き |
| キャッシュフロー図（`.cashflow`） | 出店料・仕入れ・売上の金額例 |
| オファー画面（`.offer-mock`） | 催事名・出店料 |
| フッターのリンク先 | 運営会社／利用規約／プライバシーポリシー等 |

サンプル値の箇所には注記（※〜サンプルです）を入れています。実データ確定後は注記の削除をお願いします。

## 6. 会員登録フォームの接続

ファーストビューと最終CTAの2箇所にメールアドレス入力欄を設置しています。
現在はデモ動作（確認ダイアログ表示）です。本番接続時は以下をご対応ください。

```html
<!-- index.html : 2箇所 -->
<form class="entryform entryform--hero" action="#" method="post" novalidate>
                                        ↑ 実際の登録エンドポイントURLに変更
```

`js/main.js` の「7. フォーム（デモ動作）」ブロックを削除すると、通常のフォーム送信になります。
バリデーションのみ残す場合は `window.alert(...)` の行と `e.preventDefault();` を削除してください。

## 7. デザインの意図

- **情報設計**：カード（枠線・影・角丸の多用）に頼らず、余白・罫線・文字の大小で階層を作っています。
  装飾で区切るとブロックが等価に見え、読み飛ばされやすくなるためです。
  読ませたい順に文字サイズの差をつけ、視線が上から下へ一本で流れるように構成しました。
  セクション見出しはすべて中央揃えに統一し、スクロール中の区切りを認識しやすくしています。

- **文字サイズ**：本文・ラベル・ボタン・表組みを含め、**最小16px**で統一しています。
  16pxを下回るのは「※」から始まる注釈とコピーライトのみ（`--fs-note: 14px`）で、
  CSS変数で一括管理しているため調整も容易です。
  スマートフォンでも縮小せず16pxを保つため、ファーストビューの数値3点は
  横並びから縦積みへ切り替える設計にしています。

- **配色**：ネイビー `#0E2A47` × オレンジ `#FF6B1A`。
  掛け払い（金融）を扱うサービスであるため信頼感のネイビーを土台にし、
  現場の熱量とCTAの視認性をオレンジで担保しました。既存の催事マッチングサービスで
  一般化している配色設計に沿わせ、ターゲットが違和感なく受け入れられる色域にしています。

- **ファーストビュー**：出店現場の写真を全面に敷き、ネイビーのオーバーレイをかけた上で
  白文字を載せています。写真の情報量を最大化しつつ、コピーの可読性を確保する構成です。
  さらに下部にキッチンカー／テント催事／物産催事の3業態サムネイルを並べ、
  3業態すべての事業者が「自分向けだ」と即座に判断できるようにしました。
  「0円・0円・後払い」の3点も同一画面に収め、スクロール前に登録メリットが完結します。
  高さは `max-height: 800px` で頭打ちにし、大型ディスプレイでも間延びしないようにしています。

- **入力欄の先出し**：CTAボタンだけでなくファーストビューにメールアドレス入力欄を配置。
  「まずボタンを押す」より心理的ハードルが低く、離脱前の獲得が狙えます。

- **後払いの図解**：文章だけでは伝わりにくい資金繰りのメリットを、
  従来／デバンの現金の動きを並べた図で可視化しました。

- **双方向レビュー**：業界初の機能であるため、文章ではなく実際の画面イメージで提示しています。

- **スマートフォン最適化**：現場での閲覧が中心となる想定のため、
  画面下部に追従CTAを常設（最終CTA表示時は自動で退避）しています。
