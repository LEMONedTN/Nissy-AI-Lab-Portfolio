# 画像差し替えプロンプト（そのままコピペして使用）

---

## 依頼

`deban-lp` フォルダ内のLPに配置されている**グレー（#ccc）のプレースホルダー画像**を、
実際の写真に差し替えてください。**画像を入れ替えるだけの作業**です。

対象ファイルは `deban-lp/images/` 内にあります。
差し替え後、`index.html` の該当する `src` の拡張子のみ書き換えてください。

---

## 絶対に守ること（禁止事項）

1. **HTMLの構造を崩さないこと**
   セクションの追加・削除・並び替え、class名の変更、タグの入れ替えは一切禁止です。
   変更してよいのは `<img>` の `src` 属性の**拡張子だけ**です（例：`type-tent.svg` → `type-tent.jpg`）。
   `width` / `height` / `alt` / `loading` / `class` は現状のまま維持してください。
   CSSファイル（`style/style.css`）も変更しないでください。

2. **サイトのイメージとかけ離れた画像を作らないこと**
   このLPは「キッチンカー・テント催事・物産催事の事業者向け」のビジネス系マッチングサービスです。
   実際の出店現場のリアルな雰囲気を最優先してください。
   ファンタジー調・イラスト調・過度な加工・非現実的な演出・海外の街並みは使用しないこと。

3. **人物を使う場合は必ず日本人にすること**
   欧米人・その他の国籍に見える人物は使用しないでください。
   服装や背景も日本の催事・イベント現場として自然なものにしてください。

4. **プレースホルダーとまったく同じピクセルサイズで書き出すこと**
   下の一覧に記載したサイズ・縦横比を厳守してください。
   **長方形の枠に正方形の画像を入れて縦横比が崩れることは絶対に避けてください。**
   生成AIの出力が指定比率と異なる場合は、**必ず指定比率でトリミングしてから指定サイズにリサイズ**すること。
   引き伸ばし（アスペクト比を無視した拡大縮小）は禁止です。

5. **画像内に文字を入れないこと**
   架空のロゴ・看板文字・のぼりの文字など、判読できる文字が写り込まないようにしてください。
   （読めない程度に小さく写り込むのは問題ありません）

## 各画像の内容指示

### hero-bg（1920 × 1080px／16:9）

日中の屋外イベント会場で、キッチンカーが出店している風景。
やや引きの画角で、来場者がいる活気のある雰囲気。晴天または薄曇り。

**重要な構図の指定**
この画像は左側から濃紺（#08192B）のオーバーレイが約85%の濃さでかかり、
その上に白い見出しテキストが左半分に載ります。

- 主役（キッチンカー・人物）は**画面の右寄り〜中央右**に配置すること
- 画面左側は、空・地面・ボケた背景など**情報量の少ない領域**にすること
- 画面の上下は表示環境によって切り取られるため、重要な被写体は**中央の横帯に収める**こと

### type-kitchencar（800 × 600px／4:3）

キッチンカーの販売窓口まわりの写真。
店主が調理している、または来場者に商品を手渡している様子。
車両の全景ではなく、**販売窓口を中心にやや寄った画角**が望ましい。

### type-tent（800 × 600px／4:3）

屋外のテント（タープ）出店の風景。
マルシェやフリーマーケットで、テントの下に商品が並んでいる様子。
キッチンカーは写さないこと。**テント出店であることが一目で分かる構図**にすること。

### type-bussan（800 × 600px／4:3）

物産催事・物産展の物販ブース。
地場産品や食品のパッケージ商品が什器に並んでいる様子。
屋内または屋根のある会場。**キッチンカーやテントとは明確に違う「物販」の絵**にすること。

### scene-benefit（900 × 700px／9:7）

経費削減を連想させる、実務的で生活感のある写真。以下のいずれか。

- 包材・紙コップ・洗剤などの消耗品がまとまって置かれている様子
- 高速道路を走行する車両、またはETCゲートを通過する場面

派手さは不要。**淡々とした実用的なトーン**にすること。

### avatar-01 / 02 / 03（各200 × 200px／1:1）

利用者（事業者）のポートレート。**全員日本人**。
円形に切り抜かれて表示されるため、**顔を中央に配置し、上下左右に余白を取る**こと。
自然光の屋外、または出店現場を背景にした、作り込みすぎない自然な表情。

- `avatar-01`：30代の男性。キッチンカー事業者。エプロンまたは作業着
- `avatar-02`：40代の女性。テント催事の出店者。カジュアルな服装
- `avatar-03`：50代の男性。物産催事の事業者。落ち着いた服装

## 作業手順

1. 上記の指示に沿って各画像を生成する
2. 生成した画像を**指定の縦横比でトリミング**し、**指定のピクセルサイズにリサイズ**する
3. `deban-lp/images/` に**同じファイル名（拡張子は `.jpg`）**で保存する
   例：`hero-bg.svg` → `hero-bg.jpg`
4. `index.html` を開き、該当する `<img>` の `src` の拡張子のみ `.svg` → `.jpg` に書き換える
   （`hero-bg` は `<meta property="og:image">` にも記載があるため、そちらも書き換えること）
5. 差し替えが完了した `.svg` のプレースホルダーは削除する
6. ブラウザで `index.html` を開き、PC表示・スマートフォン表示の両方で確認する
